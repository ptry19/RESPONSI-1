# Responsi 1

Project untuk Responsi 1.

## Deskripsi

Project ini berisi halaman biodata, form biodata, proses data biodata,
tabel, dan halaman cita-cita.

## Fitur

- Halaman biodata
- Form biodata
- Proses biodata
- Tampilan tabel
- Halaman cita-cita

## Cara Menjalankan

1. Simpan folder project di dalam folder `htdocs`.
2. Jalankan XAMPP.
3. Aktifkan Apache.
4. Buka browser.
5. Akses project melalui alamat:

   http://localhost/RESPONSI%201/
